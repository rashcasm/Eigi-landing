# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Business owners and lean founding teams who want to hand over actual work. The first visit should let them interact with Eigi on the homepage within ten seconds.

## Product Purpose

Eigis are AI teammates with their own computer and memory. They can research, work with files, connect to business tools and perform tasks. Eigi engineers help implement and connect the work.

## Brand Commitments

Use Eigi as the main name, “Meet your Eigi” in navigation, and computer as a capability. The user requests an abstract, artistic red panda, sparse text and Apple's emphasis on a clear primary action. A realistic animal and a timed canned demonstration were explicitly rejected.

## Evidence on Hand

The user supplied two ongoing stories: Amit helps people in Khundia with applications and information about loans; a financial learning client uses Eigi engineers for operations, support, Discord bots, and voice/video mock interviews. No quantitative results or client name supplied.

## Capabilities and Constraints

Existing React/Vite static frontend. Amit's WhatsApp number is already public in the repository. Eigi's published widget supports browser chat and voice. A specific approved agent ID is required for live use; requested from the user. Never present scripted responses as live agent output or request API secrets in chat.

## Product Principles

- Let the visitor give Eigi a task on the page.
- Show the actual response; avoid a simulated work animation.
- Keep getting started ahead of explanation.
- Keep approval and control with the visitor.
